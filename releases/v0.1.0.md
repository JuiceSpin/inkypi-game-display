# Game Display for InkyPi v0.1.0

Display your current game's artwork on an InkyPi screen, interrupting normal playlists and returning to normal content afterwards.

## Start here

Download either `inkypi-game-display-0.1.0.zip` or `inkypi-game-display-0.1.0.tar.gz`. Both contain the complete plugin, installer, source, tests, documentation and GPL-3.0 licence. Extract the archive, run `python3 scripts/install.py --check`, then follow `docs/INSTALLATION.md`.

Initial setup needs just a Home Assistant token in InkyPi API Keys, your HA base URL and your Gaming Status master sensor. Optional platform sensors provide better Xbox artwork and faster session-end detection.

## Included

- Stable Xbox titled hero artwork and PC hero/logo compositions.
- Automatic interruption and playlist restoration.
- On/off switch and a compact 24-hour × 7-day scheduler.
- 31 configurable connection, entity, timing, artwork, layout and attribute options.
- Native InkyPi API-key management, masked key status and a connection test.
- Restart recovery, source-loss timeout, image deduplication and raw-source stop confirmation.
- Compatibility-checking installer, update backups and complete option documentation.

## Compatibility and validation

This release requires InkyPi's plugin blueprint registration extension and native API-key interface. It does not add those features to an incompatible InkyPi checkout. Run the installer check before installation.

Physical tests confirmed Xbox console, Steam and Epic artwork, game switching, stable Xbox artwork and normal playlist restoration on a Pimoroni Inky Impression 7.3-inch (2025), landscape. Automated tests cover settings, scheduling, source failures and release installation/packaging. The browser test checks the settings UI using an isolated server and configuration.
